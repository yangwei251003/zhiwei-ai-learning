# 本地 Stage 7 实现快照

此目录保留同一项目本地独立演进的实现：Vue JavaScript 前端与 stage7 后端。仓库根目录的主实现是 TypeScript 前端及其配套后端。二者结构不同，不能把文件直接互相覆盖。

本次仅归档清洁源码，未复制账号配置、数据库、上传资料、依赖、运行日志或输出目录；原本机环境变量请自行重建。此快照尚未在独立环境完成整套前后端回归，不能当作已经验证的替代主版本。

前端在本目录的 frontend 中执行 npm ci / npm run dev；后端在 backend 中创建Python3.12虚拟环境，并按照自身requirements与配置模型设置新环境值。具体配置以该实现源码为准。需要本机原有资产或工作记录时应先对照迁移报告，不要因此删除原目录。
