# 知微智学认证体验设计

## 目标与范围

本阶段实现前端全局框架、登录页和注册页，严格对应阶段 4.1。目标是在三秒内建立鲜明的产品印象，同时完成可用的真实认证闭环。本阶段不实现首页、对话、资源库、学习路径、辅导和管理后台，这些页面在认证框架验收后依次推进。

## 产品定位

知微智学是面向大学生的多智能体个性化学习平台。认证页需要同时传达三件事：系统会通过对话理解学习者，能生成个性化资源，并会持续调整学习路径。主行动是进入学习工作台，不设置互相竞争的次级入口。

## 视觉方向

采用已确认的 A 方案“星图编辑部”。

- 主色为深墨绿，行动色为荧光黄，辅助色使用纸白、灰绿和少量状态色。
- 排版采用编辑式层级：明确的栏目标签、紧凑正文和有张力的品牌标题。
- 小智析析定位为“学习星图引导员”，是品牌叙事的一部分，不作为普通装饰头像。
- 右侧品牌舞台使用星图网格、轨道和粒子构成单一记忆点，避免通用紫色渐变、浮动卡片堆叠和无目的光效。
- 默认提供深色品牌体验，同时保持完整的亮色主题与可读对比度。
- 动效支持 `prefers-reduced-motion`，减少动态效果时保留状态反馈但取消持续漂浮和粒子运动。

## 页面结构

### 公共认证外壳

桌面端采用左 45%、右 55% 的全屏分栏。左侧承载表单，右侧承载品牌图像、主文案和“多智能体 / 个性化 / 即时生成”三项产品事实。移动端变为单列，品牌舞台缩为顶部视觉带，表单保持首屏可用。

### 登录页 `/login`

- 品牌标识、欢迎文案和产品副标题。
- 用户名、密码、显示密码、记住状态和登录按钮。
- 登录失败时提供输入级提示和一次性摇动反馈。
- 登录成功时切换为庆祝形象，使用品牌色遮罩完成页面过渡。
- 提供前往注册页的明确文本入口。

### 注册页 `/register`

- 与登录页共用认证外壳和视觉系统。
- 收集用户名、密码、专业和可选学习风格。
- 专业选择使用可搜索组合框；学习风格使用四项单选分段控件：视觉型、听觉型、动手型、理论型。
- 注册成功后显示小智析析欢迎语，再进入受保护工作台。

## 组件与状态边界

- `AuthShell`：认证页响应式结构、品牌舞台和主题控制。
- `BrandConstellation`：星图、粒子、吉祥物和产品事实，独立处理聚焦密度与减少动态效果。
- `LoginForm`：字段校验、提交状态和错误反馈。
- `RegisterForm`：账户字段、专业组合框、学习风格选择和分步提交反馈。
- `user` Pinia store：Token、当前用户、会话恢复、登录、注册和退出。
- Axios 请求层：Token 注入、统一错误转换和 `401` 会话失效处理。
- Vue Router：公共认证路由、受保护工作台路由和原目标地址恢复。

每个组件只拥有自身交互状态；认证事实由 `user` store 统一管理，页面不直接操作本地存储或拼接认证请求。

## 数据流

### 登录

1. 客户端校验用户名和密码。
2. 调用 `POST /api/auth/login` 并保存 Token。
3. 调用 `GET /api/auth/me` 获取当前用户。
4. 播放成功反馈并跳转到原目标地址或工作台。

### 注册

1. 调用 `POST /api/auth/register` 创建账户并获得 Token。
2. 调用 `PATCH /api/profile/current` 写入专业和认知风格。
3. 两步都成功时显示欢迎状态并进入工作台。
4. 若画像写入失败，保留已创建账户和 Token，明确提示“账户已创建，画像资料可重试保存”，避免重复注册。

### 会话恢复

应用启动时读取持久化 Token，并使用 `/api/auth/me` 验证。有效会话直接恢复；无效或过期会话清理后返回登录页。Vite 开发代理保留 `/api` 前缀，确保认证路径与 FastAPI 路由一致。

## 错误与无障碍

- 区分必填缺失、密码过短、用户名重复、凭据错误、网络中断和服务端异常。
- 所有提示使用中文且说明下一步，不暴露原始异常栈。
- 提交期间禁用重复操作，按钮保留稳定尺寸并显示明确状态。
- 输入框拥有可见焦点、关联标签、错误描述和合理自动完成属性。
- 键盘可完成全部流程；移动端触控目标不小于 44 像素。
- 颜色不作为唯一状态信号，主要文本满足 WCAG AA 对比度目标。

## 验收与验证

- 运行前端构建和类型检查。
- 运行后端认证测试，确认既有契约未回归。
- 使用真实后端完成新用户注册、画像写入、退出、重新登录和刷新恢复。
- 验证未登录访问受保护路由会返回登录页，并在登录后恢复目标地址。
- 验证重复用户名、错误密码、服务离线和画像保存失败状态。
- 在桌面 1440×900、窄屏桌面和移动端 390×844 检查布局、文字溢出和交互目标。
- 检查明暗主题、减少动态效果模式、焦点顺序和浏览器控制台错误。
- 保存登录页和注册页桌面及移动端截图，并进行人工视觉检查。

## 明确不做

本阶段不增加第三方登录、找回密码、邮箱验证、支付、营销落地页或新的后端认证机制。专业和学习风格沿用现有画像接口，不扩展用户表结构。
