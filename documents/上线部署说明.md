# 知微智学免费上线说明

## 正式架构

- 前端：Vercel（免费版）
- 后端：Hugging Face Docker Space（免费 CPU）
- 数据库、向量检索与私有文件：Supabase PostgreSQL、pgvector、Storage

该组合不要求绑定银行卡。免费后端会在长时间无访问后休眠；首次请求可能需要约 30–60 秒唤醒，随后访问恢复正常。

## Hugging Face 后端

在 Hugging Face 创建公开 Docker Space，名称建议 `zhiwei-learning-api`。将仓库中的 `hf-space/README.md` 作为 Space 根目录的 `README.md`，`hf-space/Dockerfile` 作为根目录的 `Dockerfile`，并一同上传完整 `backend/` 目录。

在 Space Settings → Variables and secrets 添加以下 **新生成且未泄露** 的 Secrets：

```text
DATABASE_URL=Supabase Connect 提供的 PostgreSQL URI（sslmode=require）
SUPABASE_URL=https://<project-ref>.supabase.co
SUPABASE_SERVICE_ROLE_KEY=<仅后端可见的 service_role key>
SUPABASE_STORAGE_BUCKET=knowledge-uploads
RAG_BACKEND=supabase
SECRET_KEY=<随机生成的长字符串>
CORS_ORIGINS=https://<你的-vercel-域名>
```

按需增加模型供应商密钥。密钥只放在 Hugging Face Secrets，绝不提交到 GitHub，也不要填入前端环境变量。部署成功后访问 `https://<账号>-zhiwei-learning-api.hf.space/health` 应返回健康状态。

## Vercel 前端

从 GitHub 导入 `yangwei251003/zhiwei-ai-learning`，将 Root Directory 设置为 `frontend`。在 Vercel 的 Production Environment Variables 设置：

```text
VITE_API_BASE_URL=https://<账号>-zhiwei-learning-api.hf.space
```

部署完成后，把 Vercel 生产域名写回 Hugging Face 的 `CORS_ORIGINS` 并重启 Space。

## Supabase 必要状态

已启用 `vector` 扩展并创建私有 `knowledge-uploads` Storage bucket 后，后端启动时运行 Alembic 迁移会创建 `knowledge_chunks` 及相应索引。浏览器只使用 anon key（如有直接 Supabase 调用）；`SUPABASE_SERVICE_ROLE_KEY` 永远只保留在后端 Secret。

## 验收

1. 打开 Vercel 域名并注册账户。
2. 发送一条对话，确认流式回复。
3. 在管理后台上传小于限制的 PDF、DOCX、TXT 或 MD，确认能检索。
4. 刷新页面，确认登录态仍有效。
5. 如首次请求超时，等待 Space 冷启动完成后重试一次。
