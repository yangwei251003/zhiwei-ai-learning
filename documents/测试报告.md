- 讯飞失败前无输出时按顺序切换智谱、蚂蚁百灵、Agnes、可选本地 Ollama；任何提供商已输出后不切换，避免重复内容；全部失败时返回真实错误，不伪造结果

## 异常场景结果

| 场景 | 结果 |
| --- | --- |
| 空消息 | 发送按钮禁用 |
| 5000 字输入 | 前后端均接受 |
| SSE 断网 | 显示重连并恢复请求 |
| Token 过期 | 清理状态并跳转登录 |
| 模型接口失败 | 红色错误提示，不返回假数据 |
| 知识库为空 | 正常通用回答，并显示未接入提示 |
| 重复用户名 | HTTP 409，友好提示 |
| 文件过大 | 前端预检、后端再次拦截 |
| 浏览器刷新 | 登录状态保持 |

## 性能与工程指标

- 前端生产构建通过。
- 主入口脚本约 27.16 kB（gzip 10.06 kB）；页面均为路由懒加载。
- Mermaid 及图形能力拆为独立懒加载块，不阻塞首页入口。
- Element Plus 改为按需引入 `ElButton`、`ElIcon`。
- 实拍图片使用浏览器懒加载；首页短视频为 640 × 360 SD、约 430 kB，并配置 poster、静音自动播放、循环和减少动态偏好降级。首屏 IP 图片已转为 WebP（约 28 kB）并延后加载视频，避免影响 LCP。
- 资源列表记录实际加载耗时；接口目标为 1 秒以内。
- Lighthouse（生产预览 `127.0.0.1:4173`）：Performance **94**，FCP **2.0 s**，LCP **2.6 s**，TBT **120 ms**，达到首页 Performance ≥ 75 的验收目标。
